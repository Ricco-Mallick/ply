What to do when it opens

  1. Free roam. Click the scene, walk with W A S D, look with the mouse. The floor is the real floor; the spawn is at the door.
  2. Change view. Plan for a top-down floor plan, Dollhouse for the cutaway, Views for saved shots.
  3. Search a place. Type a room or object name, pick it, and follow the route: it is computed on the occupancy grid, so it bends around the desks instead of through them.
  4. Measure. Measured overlays the derived shell (walls, openings, object boxes) so the splat and the geometry can be compared.
  5. On Android Chrome, the AR button starts an immersive session and projects the same route on the real floor, aligned with two taps.

Reconstruction behind the link

Ply's own pipeline made the scene from eight minutes of handheld video: 542 solved poses at 0.82 px mean reprojection, a floor at 2.5 mm residual, 194 detected objects, 1.35 M Gaussians in a 37 MB SPZ, plus a 12.9 MB phone file and a 72-chunk LOD set so the viewer picks what the device can carry.

Browsers

Chrome or Edge on desktop for the full walkthrough; Safari on macOS and iOS loads the model and capture pages. AR needs WebXR, so it is Android Chrome today; on iPhone the AR entry point is hidden rather than broken. Every URL here returned HTTP 200 when this document was written; if a scene does not load, open https://ricco.codes/ply/ and use the entry card, which links to the same scenes.
